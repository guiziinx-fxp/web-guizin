Web-Guizin

Sobre o projeto

O Web-Guizin é um site pessoal desenvolvido para apresentar um pouco sobre minha identidade, meus interesses e meus objetivos profissionais.

O projeto foi desenvolvido utilizando HTML e CSS, com os conteúdos estudados nas aulas de Desenvolvimento Front-End para Web.

Páginas

- "index.html" — Página principal, com informações sobre mim, meus interesses, objetivos, rotina de estudos e formulário de contato.
- "interesses.html" — Página complementar com meus interesses, meu estilo e um áudio.

Recursos utilizados

- HTML5
- CSS3
- Links internos e externos
- Imagem com texto alternativo
- Lista
- Tabela
- Formulário
- Áudio com controles de reprodução
- Estrutura semântica com cabeçalho, menu, seções e rodapé

Como abrir o projeto

1. Abra a pasta "Web-Guizin" no Visual Studio Code.
2. Abra o arquivo "index.html".
3. Execute o arquivo no navegador.
4. Utilize o menu para navegar entre as páginas.

Fontes

Os conteúdos e exemplos utilizados no projeto foram baseados nas aulas e materiais da disciplina de Desenvolvimento Front-End para Web.

Os arquivos de imagem e áudio utilizados fazem parte do projeto apenas como recursos para demonstração das funcionalidades HTML.
